# Support

## Usage questions

Use [GitHub Discussions](https://github.com/newpoluton-alt/RustTorch/discussions)
for setup help, API questions, design discussion, and showing work. Search the
README, API docs, platform guide, and existing discussions before posting.

Community support is best effort. The project does not provide private support,
service-level guarantees, or guaranteed compatibility outside documented
scope.

## Issues

Use the structured issue forms for reproducible defects, scoped feature
proposals, PyTorch compatibility gaps, and measured performance problems.
Issues must contain enough evidence to act on; maintainers may move or close
requests that are support questions, duplicates, stale, unsafe, or outside the
current milestone.

Vulnerabilities must use [private security reporting](SECURITY.md). Conduct
reports follow the [Code of Conduct](CODE_OF_CONDUCT.md). Do not put sensitive
details in a public support channel.
