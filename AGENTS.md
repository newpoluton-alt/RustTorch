# Contributor instructions

Read and follow `CONTRIBUTING.md` before changing this repository.

## Branch names

Never create branches with the `codex/` prefix. Use `b/` for features or general
implementation, `f/` for bug fixes, and descriptive prefixes such as `docs/`,
`test/`, or `chore/` for other work. Follow an exact branch name supplied by the
user. This standing rule applies to future work; existing branch names do not
need to be rewritten to satisfy it.
